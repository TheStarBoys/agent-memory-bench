# N2 · 原文回链准确度

## 考什么

**每条记忆能否指回原文的准确区间**——起止两端都对，不是只记起点。

只记起点等于往回走要猜，而猜出的区间回答的是"这条记忆附近说了什么"。

## 为什么公开题库测不了

现有 harness 的 `retrieve_entries()` 返回条目列表，**没有"出自原文哪一段"这一维**。
LoCoMo 的 `evidence` 字段最接近——它标了 ground-truth 的轮次 ID——
但它用来判**检索对不对**，不是判**系统自己声称的来源对不对**。

区别是关键的：LoCoMo 问「你捞到正确的轮次了吗」，N2 问「你说这条记忆来自 X，X 真的是它的来源吗」。
一个系统可以检索全对，同时把每条记忆的来源标错。

## 判分

确定性。逐条比对系统自报的来源区间与 ground-truth 区间：

| 指标 | 说明 |
|---|---|
| 覆盖率 | 有多少条记忆**给得出**来源 |
| 精确率 | 给出的区间是否**准确**（起止都对） |
| 越界率 | 区间是否包含了不属于该记忆的内容 |

⛔ **"给不出区间"与"给出错误区间"必须分开记。** 前者是诚实的能力缺失，
后者是编造——把两者混成一个数，会让沉默的系统看起来比说谎的系统更差。

## harness 需要能做什么

- 拿到系统对每条记忆自报的来源指针
- 按指针取回原文字节，与 ground-truth 区间比对

## 不支持时

多数系统只记录"来自哪次会话"或什么都不记。报 **不支持**。
