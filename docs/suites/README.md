# 自研套件

## 为什么存在

[公开题库](../benchmarks.md) 15 个，**全部是「喂对话、问问题」的形状**，
没有一个提供可被求值的"现实"。逐条对过之后，四类能力**零覆盖**。

```
公开题库已覆盖  检索质量 · 冲突消解/知识更新 · 诚实弃权 · 记忆幻觉 · 成本与延迟
自研套件覆盖    N1 对现实求值 · N2 原文回链 · N3 推理链正确性 · N4 治理可审计
```

**自研题的范围就是下面这八类，其余一律用公开题库，不重复造。**

## 八类，两条推导各出一半

题目从两条独立的推导线来。**两条对上的地方最可信，只有一条指出的最值得看。**

### 防守性推导：公开题库漏了什么

| # | 题型 | 一句话 |
|---|---|---|
| [N1](n1-reality.md) | **对现实求值** | 外部世界变了，系统能否发现某条记忆已经不成立 |
| [N2](n2-provenance.md) | **原文回链准确度** | 每条记忆能否指回原文的**准确区间**，起止都对 |
| [N3](n3-reasoning.md) | **推理链正确性** | 结论之外，**推导链每一步**是否成立、前提是否指得出来源 |
| [N4](n4-governance.md) | **治理可审计性** | 谁写的、谁能读、删除后审计轨迹是否留存 |

### 进攻性推导：记忆本该是什么样

从人的记忆反推（[`../cognition.md`](../cognition.md)），
这四类**两条推导都没覆盖**，且逐条过了「公开题库结构上测不到」这道门槛：

| # | 题型 | 一句话 | 需要声明能力 |
|---|---|---|---|
| [N5](n5-consolidation.md) | **巩固与遗忘** | 该留的留了、**该丢的丢了吗**——判据是需求概率 | 外部观察**不需要** |
| [N6](n6-structure.md) | **关联结构** | 可达性与扇形干扰，**两条曲线一起报** | **不需要** |
| [N7](n7-calibration.md) | **置信度校准** | 它知不知道自己什么时候会错 | `CONFIDENCE` |
| [N8](n8-induction.md) | **归纳与可废止推理** | 归纳出规律，且**例外不推翻规律** | 三个问题**不需要** |

⭐ **N5 外部观察 · N6 · N8 三个问题不需要声明任何能力**——
它们只用 `search` 和 `answer`，能从外部观察到的东西不要求系统配合。
这三种**全员参赛**，是八类里唯一没有大面积「不支持」的。

⚠️ N1–N4 各自也被认知推导修正了三处，见
[`../cognition.md`](../cognition.md#对现有四类的三处修正)。

## 三条设计约束

### ① 全部确定性判分，不用 LLM 评委

评委模型换一个分数就漂，而这四类要当**长期可比**的尺子。
公开基准那边的 J 分已经证明了后果：Zep 自称 84% → Mem0 复现说 58.44% → Zep 反驳说 75.14%，
同一个系统、同一个数据集、三个数。

⚠️ **这条约束是有代价的，代价必须写在明面上**，不能只享受它的好处：

| 套件 | 坎在哪 | 裁决 |
|---|---|---|
| **N1** | 要求 `unknown` 说清"为什么没能判定"，而理由是散文 | 改为结构化 `grounds`（路径/键/id），**判分不读散文** |
| **N3** | 要求判"每一步是否成立"，而自由文本推理步骤只有评委判得了 | **语料改为合成**：claim 是三元组，rule 取自封闭词表。代价是 N3 测不到自然语言推理，只测结构化多跳的链条纪律 |
| **N8** | 归纳出的规律若要求系统交出来，就预设了它有显式规则库 | **判分全部行为化**：只看三个探针的答案，不要求交出规则 |

一个能确定性复现的窄尺子，好过一个每次换评委就漂的宽尺子。
自然语言那一半交给公开题库的端到端准确率——那本来就是它们的活。

### ② 三种结果分开记，任意两种合并都会废掉这把尺子

大多数系统没有回链、没有推导链、没有主体。它们在 N1–N4 上应当报 **不支持**，
**而不是 0 分**。

⚠️ 「不支持 vs 0 分」这个二分是不够的。实际有三种结果，**判分位置各不相同**：

| 结果 | 含义 | 计入分母 | 报告位置 |
|---|---|---|---|
| **不支持** | 没声明这个能力 | ❌ 否 | 独立的「不支持」列 |
| **失败** | 声明了，这次没做成 | ✅ 是，记为未答对 | 分数，**并单独报 Failed 率** |
| **做错** | 做了，答案不对 | ✅ 是 | 分数 |

⛔ **「不支持」与「做错」合并** → 这把尺子第一天就废，
而且会让人以为这四类是我们编出来给自己送分的。
⛔ **「失败」与「不支持」合并** → 开了一个后门：
声明全部能力、次次返回失败，就换到一个永远不掉分的位置。

⚠️ 「不支持不计分」还会反向催生**少声明**的动机。靠[声明与参与](../report.md)曝光，
细则见[原则①](../adapters/README.md#p1)。

N4 另有一档 **部分支持**（未申报 `storage_locations()`，删除只验到过滤层），
既不是不支持也不是通过，单列。

### ③ 需要有状态的世界，所以需要自己的适配器协议

现成评测框架 的五方法接口把记忆系统当纯函数。N1–N4 要求评测器能**改变外部现实**，
再问系统发现没有；N5 / N7 / N8 更进一步，要求世界**有统计结构**——
事件流、频率、间隔、与频率正交的显著性、需求概率、带例外的规律
（[world.md](../adapters/world.md#事件流与统计结构)）。世界通过 `setup(WorldHandle)` 交给被测系统——
**文件树只读挂载、时钟与事实表是只读端点而非快照值**，改动不通知任何人。

协议见 [`../adapters/README.md`](../adapters/README.md)，
世界见 [`../adapters/world.md`](../adapters/world.md)。
