# 自研套件

## 为什么存在

[公开题库](../benchmarks.md) 15 个，**全部是「喂对话、问问题」的形状**，
没有一个提供可被求值的"现实"。逐条对过之后，四类能力**零覆盖**。

```
公开题库已覆盖  检索质量 · 冲突消解/知识更新 · 诚实弃权 · 记忆幻觉 · 成本与延迟
自研套件覆盖    N1 对现实求值 · N2 原文回链 · N3 推理链正确性 · N4 治理可审计
```

**自研题的范围就是这四类，其余一律用公开题库，不重复造。**

## 四类

| # | 题型 | 一句话 | 判分 |
|---|---|---|---|
| [N1](n1-reality.md) | **对现实求值** | 外部世界变了，系统能否主动发现某条记忆已经不成立 | 确定性 |
| [N2](n2-provenance.md) | **原文回链准确度** | 每条记忆能否指回原文的**准确区间**，起止都对 | 确定性 |
| [N3](n3-reasoning.md) | **推理链正确性** | 结论之外，**推导链每一步**是否成立、前提是否指得出来源 | 确定性 |
| [N4](n4-governance.md) | **治理可审计性** | 谁写的、谁能读、删除后审计轨迹是否留存 | 确定性 |

## 三条设计约束

### ① 全部确定性判分，不用 LLM 评委

评委模型换一个分数就漂，而这四类要当**长期可比**的尺子。
公开基准那边的 J 分已经证明了后果：Zep 自称 84% → Mem0 复现说 58.44% → Zep 反驳说 75.14%，
同一个系统、同一个数据集、三个数。

### ② 「不支持」必须与「做错了」分开记

大多数系统没有断言、没有回链、没有主体。它们在 N1–N4 上应当报 **不支持**，
**而不是 0 分**。

把"做不到"和"做了但做错"记成同一个数，这把尺子第一天就废了——
而且会让人以为这四类是我们编出来给自己送分的。

### ③ 需要有状态的世界，所以需要自己的适配器协议

现成 harness 的五方法接口把记忆系统当纯函数。N1–N4 要求 harness 能**改变外部现实**，
再问系统发现没有。协议见 [`../adapters/README.md`](../adapters/README.md)。
