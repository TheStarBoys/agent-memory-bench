# N8 · 归纳与可废止推理

## 考什么

**从观察到的世界里归纳出规律，并且在遇到例外时不把规律整个丢掉。**

## 与 N3 的边界

这两类都叫「推理」，但测的是相反的两半，**必须分开**：

| | [N3 推理链](n3-reasoning.md) | N8 归纳 |
|---|---|---|
| 方向 | **演绎**：给定前提推结论 | **归纳**：从多个个例推出规律 |
| 逻辑 | **单调**：加新前提不会推翻旧结论 | **非单调**：一个例外不作废规律 |
| 规律从哪来 | 题目给定 | ⭐ **系统自己从世界里发现** |
| 规则词表 | 封闭、单调（`TRANSITIVE` / `SUBSTITUTE` …） | 需要 `DEFAULT` / `EXCEPT` 与规律强度 |

⛔ **不把 N8 并进 N3。** N3 的价值来自判分干净——
它的封闭规则词表全是单调的，加进非单调规则之后，
「哪个默认规则该被例外压过」本身就会有争议，
而那正是 N3 想避开的东西。**宁可多一类，不把 N3 做脏。**

## 为什么公开题库测不了

真实世界的规律几乎**全是可废止的**：「鸟会飞」，企鹅除外，规则不因此作废。
而公开题库要么给定前提让你演绎，要么问一个具体事实。

**没有一个题库提供「一个有统计规律、且有明确例外的世界」让系统去观察。**
这和 [N1](n1-reality.md) 缺不了世界是同一个结构性原因——
归纳需要**很多个例**，而个例只能来自一个持续产生事件的世界。

⚠️ 顺带一提，「规则层要像数学一样严谨可证明」是一个**设计目标，不是对人的描述**——
人的语义知识是原型式、家族相似式的。选可证明的那一边对 agent 是对的，
但那意味着这个规则层不再是人那种规则层，评测方式不能互相借。
见 [`../cognition.md`](../cognition.md)。

## ⛔ 判分只看行为，不要求系统交出规则

**最容易破坏[机制中立](../adapters/README.md#p2)的做法**，
是要求系统输出它归纳到的规则列表——那预设了它有一个显式的规则库，
对隐式泛化的系统不公平。

所以 N8 的判分**全部是行为性的**：

```
世界里有一条成立率 ~90% 的规律，若干正例，以及明确的例外个例
评测器只问三种问题，全部通过 answer()
```

| 探针 | 问什么 | 期望 |
|---|---|---|
| **① 泛化** | 一个**没见过**的、符合规律的新个例 | 答对 → 说明归纳到了 |
| **② 例外** | 那个明确的例外个例 | 答**例外的值**，不是规律的值 |
| **③ 规律存活** | 见过例外**之后**，再问另一个新的正例 | ⭐ 仍答规律的值 |

**第三个探针是这一类的要害。** 它区分三种系统：

| 行为 | 判定 |
|---|---|
| ①✅ ②✅ ③✅ | ✅ 归纳到了规律，且例外没有推翻它 |
| ①✅ ②✅ ③❌ | ❌ **过度修正**——一个反例就把规律扔了 |
| ①✅ ②❌ ③✅ | ❌ **过度泛化**——规律压过了明确的例外 |
| ①❌ | ❌ 根本没归纳出来 |

⛔ 中间两行**在只判最终答案的题库里会被算成「答错一道题」**，
而它们其实是两种相反的毛病。分开记。

### 规律强度

第二组：世界里放**成立率不同**的规律（60% / 80% / 95%），
测系统的应用倾向是否随之变化。

⚠️ 判分口径是**单调性，不是绝对值**——
「95% 的规律比 60% 的更常被应用」是可判的，
「60% 的规律应该被应用多少次」不是。

### 可选：交出推导链

声明 `INDUCTION` 的系统可以额外给出可废止推导链，
用扩展的规则词表（`DEFAULT` / `EXCEPT` + 强度）。
**这一档是加分项，不是参赛条件**——不给链条照样跑上面三个探针。

## 评测器需要能做什么

- 世界里能种下**带明确例外的统计规律**，成立率可控
- 保留一批**从未在世界里出现过**的正例，用作泛化探针
- 控制例外出现的时机，以便在「见到例外之后」再问③

世界的要求见 [`../adapters/world.md`](../adapters/world.md#事件流与统计结构)。

## 不支持时

**基线三个问题只需要 `ANSWER`，不需要额外声明**——
任何能端到端答题的系统都能参赛。

未声明 `INDUCTION` 的，只是不跑「交出推导链」那一档，记不支持，
⛔ **不影响三个问题的成绩**。
