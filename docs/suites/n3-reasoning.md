# N3 · 推理链正确性

## 考什么

**结论对之外，推导链的每一步是否成立、每个前提是否指得出来源。**

## 为什么公开题库测不了

所有公开题库只判**最终答案**。于是：

**结论蒙对而链条错误，判满分。**

多跳题尤其如此——LoCoMo 有 282 道多跳题，判的全是最后那个字符串。
一个系统可以靠语料里的表面共现拿到正确答案，而它走的路径完全不成立。

## 判分

确定性。系统要给出的不只是结论，还有：

| 要素 | 判什么 |
|---|---|
| 结论 | 对不对 |
| 每一步 | 这一步的推导是否成立 |
| 每个前提 | 是否指得出它出自哪条记忆 |
| 未决 | 推不出来时，**是否说清缺哪个前提** |

⛔ **「没能判定」永不折进「判定为否」。** 一个说"我缺前提 X"的系统，
比一个直接答"否"的系统更有用，判分必须体现这一点。

## harness 需要能做什么

- 拿到结构化的推导链，不只是答案字符串
- 校验链上每个前提确实存在于该系统的记忆里

## 不支持时

大多数系统只返回答案。报 **不支持**——注意这**不等于**它们答不对，
只是它们无法回答"你是怎么得出来的"。
