# N3 · 推理链正确性

## 考什么

**结论对之外，推导链的每一步是否成立、每个前提是否指得出来源。**

## 为什么公开题库测不了

所有公开题库只判**最终答案**。于是：

**结论蒙对而链条错误，判满分。**

多跳题尤其如此——LoCoMo 有 282 道多跳题，判的全是最后那个字符串。
一个系统可以靠语料里的表面共现拿到正确答案，而它走的路径完全不成立。

## ⛔ 语料必须是合成的，否则这一类交付不出来

[约束①](README.md)要求确定性判分，而这一类要判「每一步推导是否成立」。
**如果 `Step` 是自由文本，这两条要求互斥**——判断一个任意自然语言推理步骤
成不成立，正是需要评委的那件事。

裁决：**收紧题目，不放弃确定性。** N3 不使用自然语料，而是在一张
**已知的类型化事实图**上合成：

| 收紧的地方 | 结果 |
|---|---|
| 事实是三元组 `subject\|relation\|object` | 命题可以逐字比对，不需要语义等价判定 |
| 题目由 评测器 从图上生成 | **合法推导链是一个可枚举的有限集**（生成器的闭包） |
| `rule` 取自[封闭词表](../adapters/protocol.md#数据类型) | 不在表里的规则一律判该步不成立 |
| `Step` 有 `step_id`，`Premise` 带 `kind` | 接链靠 id，不靠 claim 字符串匹配 |

**代价要说清楚：N3 因此测不到自然语言里的推理，只测结构化多跳的链条纪律。**
这是有意的取舍——一个能确定性复现的窄尺子，好过一个每次换评委就漂的宽尺子。
自然语言那一半交给公开题库的端到端准确率。

## ⚠️ 范围声明：测演绎，不测归纳

[封闭规则词表](../adapters/protocol.md#数据类型)里七条规则**全是单调的**。
它表达不了这种形态：

> 从世界里观察到「A 类事物通常具有性质 P」，而这次遇到的 a 是个例外。

而真实世界的规律几乎**全是可废止的**（「鸟会飞」，企鹅除外，规则不因此作废）。
所以 N3 测的是**给定前提做严格演绎**，⛔ **不包括归纳出规则、再正确处理例外**。

这不是缺陷，是范围——但必须写在这里，否则「推理链」三个字会被读成包含归纳。
归纳与可废止推理是[一个独立的候选类](../cognition.md#gaps)，
边界怎么划待裁决。

## 判分

确定性。四个要素分开记：

| 要素 | 判什么 | 怎么判 |
|---|---|---|
| **结论** | 对不对 | 与 ground-truth 三元组逐字比对 |
| **每一步** | 这一步的推导是否成立 | `(premises, rule) → claim` 是否落在生成器闭包内 |
| **每个前提** | 是否指得出它出自哪条记忆 | `Premise(kind="entry")` 的 `ref` 是否解析得到本系统的 `Entry` |
| **未决** | 推不出来时，是否说清缺哪个前提 | `Answer.missing` 非空且每项都是有效 `claim_id` |

派生指标：

```
结论准确率     结论对的题 / 全部题
链条完好率     结论对 **且** 每一步都成立的题 / 全部题
蒙对率         结论对但链条有不成立步骤的题 / 结论对的题
前提落地率     解析得到的前提 / 全部前提
```

⚠️ **蒙对率是这一类存在的理由。** 公开题库只报第一行，N3 报第二、三行。
两者的差就是「表面共现能贡献多少分」。

⛔ **「没能判定」永不折进「判定为否」。** 一个说"我缺前提 X"的系统，
比一个直接答"否"的系统更有用，判分必须体现这一点：
`missing` 非空且有效的题进**未决**列，不进错误列——和
[N1 的弃权](n1-reality.md#六格全报)一样，未决进分母但不算错。

## 评测器 需要能做什么

- 持有生成题目的那张事实图，以及它的推导闭包
- 拿到结构化的推导链（`Answer.derivation`），不只是答案字符串
- 校验链上每个前提确实存在于该系统的记忆里

## 不支持时

大多数系统只返回答案。报 **不支持**——注意这**不等于**它们答不对，
只是它们无法回答"你是怎么得出来的"。
