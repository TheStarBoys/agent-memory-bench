# 抽样方法论：小样本就要能给出全量的答案

> **这是本项目的一条基础思想，与「不用评委」「三态分列」同级。**

## 一句话

**抽样检查统计出来的分数，与跑全量的分数，在概率分布上应当一致。**

所以：⛔ **每一个抽样分都必须带置信区间**。
一个不带区间的抽样分是在骗人——它假装自己是全量分。

## ⛔ 「样本小」不等于「没意义」

样本小，意味着**区间宽**，不意味着结论无效。同一个真值 0.52：

| 题数 | 估计 | 95% 区间 | ± | 最小可分辨差异 |
|---:|---:|---|---:|---:|
| 7 | 0.520 | [0.215, 0.810] | 0.297 | 0.480 |
| 20 | 0.520 | [0.316, 0.717] | 0.201 | 0.389 |
| 50 | 0.520 | [0.385, 0.652] | 0.133 | 0.264 |
| 200 | 0.520 | [0.451, 0.588] | 0.069 | 0.137 |
| 1986（全量） | 0.520 | [0.498, 0.542] | 0.022 | 0.044 |

⭐ n=7 的分**是有效的无偏估计**，只是它说的是「0.52，上下浮动 0.30」。
⛔ 把它当成 0.52 用是错的；说它「没有价值」也是错的。

## ⭐ 反过来算才是真正有用的

**要分辨两个系统，需要多少题？** 这个数算得出来，⛔ 不用拍脑袋：

| 要检测的差异 | 每组需要 |
|---:|---:|
| 20 个百分点 | **92 题** |
| 10 个百分点 | 384 题 |
| 5 个百分点 | 1556 题 |
| 2 个百分点 | 9775 题 |

⭐ **要分辨「明显更好」，92 题就够了——不用跑 1986。**
⚠️ 而要证明「好 2 个点」，一万题都不太够——
那种差距在这个尺度上本来就说不清。

## 三条硬规矩

### ① ⛔ 抽样分必须带区间

报告里每个抽样分后面跟 `[low, high] n=…`。
⛔ 只给点估计的抽样分不许出现。

### ② ⛔ 区间重叠时不许声称谁更好

两条臂的区间重叠 = 在这个样本量下**分不出高低**。
⚠️ 那不是「一样好」，也不是「A 更好但不显著」——是**这次跑答不了这个问题**。

报告里给的是：

```
⛔ 分不开：差 0.090，但 n=20 只能分辨 ≥0.389 的差异——不许声称谁更好
```

### ③ ⭐ 分层是默认，因为它更省题

[LoCoMo 五类占比](benchmarks.md) 42/22/16/14/5%。

- **简单随机**抽 50 题：占 5% 的开放域推断类**很可能一道都没抽到**
- **分层**抽 50 题：每类都有，而且层内方差比总体方差小，
  ⭐ **同样的 n 给出更窄的区间**

⚠️ 分层估计要按层在全量里的占比加权还原，
并做有限总体校正——抽了一层里的大部分时，方差要缩。

## 用哪个区间公式

**Wilson**，⛔ 不用正态近似 `p ± z·√(p(1-p)/n)`。

⚠️ 正态近似在 p 接近 0 或 1、或者 n 小的时候会给出**越界的区间**
（比如 [-0.1, 0.3]），而我们这里两种情况都常见：
弃权率天然接近 0 或 1，小样本是常态。Wilson 在小 n 上仍然可靠。

## ⛔ 抽样本身必须可复现

| | |
|---|---|
| 策略与种子 | 进报告——⛔ 不记的话，两次跑的差可能全来自抽到了不同的题 |
| 分层分布 | 进报告——⚠️ 要看得到每类抽了几条，才知道有没有漏类 |
| 语料截断 | 进报告——⛔ 截了语料要丢掉证据被截掉的题，丢了几道也要记 |

## ⭐ 抽样有效性要被验证，不能只是声称

「小样本与全量一致」是一个**可以证伪的主张**，所以要测它：

    对同一条臂，跑全量得到 P，抽 n 题得到 p̂ 和区间 I
    ⭐ 反复抽多次：P 落在 I 内的比例应当接近 95%

⚠️ 落不进去就说明抽样有偏——那时候要修的是抽样，不是分数。

## 怎么用

```sh
# 快速判断：92 题足够分辨「明显更好」
python -m amb.cli --bench locomo --sample stratified:92

# 精细比较：要分辨 10 个百分点
python -m amb.cli --bench locomo --sample stratified:384

# 复现某几道题
python -m amb.cli --bench locomo --sample ids:conv-26#167,conv-26#178
```

⚠️ 题数与**语料量**是两件事：`--max-turns` 单独控语料，
⛔ 对每条都调 LLM 的系统，语料量才是那个约束。
见 [`integrating.md`](integrating.md)。
