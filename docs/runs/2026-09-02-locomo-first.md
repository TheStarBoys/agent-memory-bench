# 2026-09-02 · LoCoMo 首次多系统对比

> ⭐ **第一次把真被测系统和对照组放在同一张表里。**
> ⛔ 但这是机制验证，不是评测结果——理由见[末尾](#不能从这份结果得出的)。

## 怎么跑的

```sh
python -m amb.cli --bench locomo --sample stratified:63 \
  --max-convs 1 --max-turns 200 \
  --arms bm25,null,naive_rag,mem0_raw --no-answer
```

| | |
|---|---|
| 题库 | LoCoMo `3eb6f2c585f5e1699204e3c3bdf7adc5c28cb376` |
| 抽样 | 分层 63 题 / 1986，seed=42 → ⚠️ 实得 **58 题**（截语料后丢掉了证据缺失的题） |
| 语料 | 1 个对话前 200 轮 |
| embedding | `Qwen/Qwen3-Embedding-4B` @ siliconflow |
| 判分 | ⭐ 靠 LoCoMo 的 `evidence` 字段判检索——**不生成答案**，所以量的是记忆层本身 |
| mem0 | `mem0ai 2.0.19`，⚠️ 这次跑的是 `infer=False` 那一档 |

## 结果

### 检索质量（主指标 `evidence_recall`）

| 臂 | 分 [95% 区间] | Δ vs 地板 |
|---|---|---|
| `naive_rag`（对照） | **0.661** [0.533, 0.770] | 地板 |
| `mem0_raw`（被测） | **0.661** [0.533, 0.770] | ⛔ 分不开（差 +0.000，n=58 只能辨 ≥0.217） |
| `bm25`（对照） | 0.613 [0.484, 0.727] | 参照 |
| `null`（对照） | 0.000 [0.000, 0.062] | 参照 |

### 逐类拆开——⛔ 总分会把结构糊掉

| 类 | n | `bm25` | `naive_rag` | `mem0_raw` |
|---|---:|---:|---:|---:|
| 时间推理 | 15 | **0.800** | 0.800 | 0.800 |
| 单跳事实 | 28 | 0.516 | **0.710** | 0.710 |
| 弃权 | 14 | **0.714** | 0.500 | 0.500 |
| 多跳 | ⚠️ 1 | 0.000 | 0.000 | 0.000 |

⭐ `bm25` 总分更低，但在**弃权**那一类上反而最高（0.714 vs 0.500）。
⚠️ 多跳只抽到 1 题，⛔ 那一格不能当真。

### 成本 × 质量

| 臂 | 质量 | 每条摄入 | 每次回答 | 总耗时 | 判定 |
|---|---:|---:|---:|---:|---|
| `naive_rag` | 0.661 | 0.130s | 1.766s | 1.0x | 地板 |
| `mem0_raw` | 0.661 | 0.920s | 0.854s | 1.8x | ⛔ **被地板压制** |
| `bm25` | 0.613 | <0.001s | <0.001s | <0.001x | ⚠️ 更快但更差 |
| `null` | 0.000 | <0.001s | <0.001s | <0.001x | ⛔ 被地板压制 |

## ⭐ 这次跑得出的三个结论

### 1. 关掉抽取的 mem0 与朴素 RAG **分数完全一致**

⚠️ 不只是总分一样——**逐类每一格都分毫不差**（0.000 / 0.800 / 0.710 / 0.500）。

那不是巧合：`infer=False` 之后，mem0 就是「同一个 embedding 模型 + 向量检索」，
与我们那 92 行的朴素 RAG **是同一个东西**。

⭐ 所以：**mem0 的价值全在 LLM 抽取那一层**。
去掉它，剩下的部分不比一个朴素 RAG 多任何东西——⛔ 而且还贵 1.8 倍。

### 2. `bm25` 在弃权题上反超

总分 0.613 < 0.661，但弃权那一类 **0.714 > 0.500**。

⚠️ [LoCoMo 有 22% 是弃权题](../benchmarks.md)。
⛔ 只看总分会漏掉「谁在哪一类上强」——这就是逐类分开报的理由。

### 3. ⭐ 区间重叠时框架**拒绝排名**

`mem0_raw` 与 `naive_rag` 差 0.000，报告直接写：

> ⛔ 分不开（差 +0.000，n=58 只能辨 ≥0.217）

⚠️ 那不是「一样好」，是**这次跑答不了这个问题**。
要答就加题：见 [`../sampling.md`](../sampling.md#how-many)。

## ⛔ 不能从这份结果得出的

| ⛔ | 为什么 |
|---|---|
| 「mem0 不如朴素 RAG」 | ⚠️ 这次跑的是 `infer=False`，**抽取版没进来**（200 轮 × 36.7 秒 ≈ 2 小时） |
| 「naive_rag 比 bm25 好」 | 区间重叠，n=58 只能分辨 ≥0.217 的差异 |
| 任何关于多跳的结论 | ⚠️ 只有 1 题 |
| 任何跨 backbone 的结论 | 只跑了 Qwen3-8B 一个 |

⭐ 这份结果**证明的是机制**：抽样带区间、区间重叠不排名、
逐类分开、成本参与判定——每一条都在真数据上生效了。
