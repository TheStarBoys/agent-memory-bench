<a id="three-findings"></a>

## 三个发现

### ⭐ ① 抽取层的价值，全在弃权和多跳上

`mem0_raw`（关掉 LLM 抽取）与 `naive_rag` 的逐类分数：
**四类完全相同**，只有单跳差 0.014。

⚠️ 这是**第三次**观察到「关掉抽取的 mem0 ≈ 朴素 RAG」
（[前一次在 58 题上](2026-09-02-locomo-first.md)，这次在 126 题上）。
⭐ 一个跨样本稳定的观察。

开了抽取之后拉开的是：**弃权 +0.195**、**多跳 +0.095**、单跳 +0.029。
⛔ 时间推理和开放域**一点没动**。

⚠️ 但每一项差距都在 n 太小的格子里——⛔ 这是**观察，不是结论**。

### ⭐ ② bm25 在弃权题上再次反超朴素 RAG

0.639 vs 0.444。⚠️ 这也是第二次独立出现了。
⭐ 而 `mem0` 是唯一在这一类上压过 bm25 的（0.667）。

⚠️ 弃权题占 LoCoMo 的 22%，⛔ 比多跳还多。
一个只会返回 top-k 的系统在这一类上必然吃亏——
⭐ 值得单独立一个探针去查「为什么词面匹配反而更会弃权」。

### ⛔ ③ 摄入成本随库增长——估算会系统性偏低

| | 估的 | 实际 |
|---|---:|---:|
| mem0 摄入 419 轮 | 50 分钟 | **72 分钟**（4345s） |
| 每条 | 7.4s | **10.0s** |

⚠️ 7.4s 是拿**前 160 条**量的。归并型系统要跟已有记忆比对，
库越大越慢——⛔ **小样本量出来的每条成本一定偏低**。

⭐ 同一现象在 [A-mem](../../src/amb/adapters/impl/a_mem/README.md#growth) 上严重得多
（3.3s → 24.8s，8 条之内涨 7 倍，因此**跑不完**这个规模，不在本表内）。
⚠️ mem0 是同一类形状，只是程度轻。

<a id="不能从这份结果得出的"></a>

## ⛔ 不能从这份结果得出的

| | |
|---|---|
| ⛔ **「mem0 比朴素 RAG 强」** | +0.088 < 可分辨阈 0.158。⚠️ 区间重叠一大半 |
| ⛔ **任何逐类排名** | 逐类 n 都不够：单跳 64 需 23pp、弃权 35 需 27pp、⚠️ 多跳 9 和开放域 5 **完全不能引用** |
| ⛔ **外推到别的语料** | 只跑了**一个对话**——同一对人的同一段关系史，不是独立样本 |
| ⛔ **回答质量** | 这是检索档。⚠️ 检索到证据 ≠ 答得对 |
| ⛔ **完整的被测系统清单** | [A-mem 跑不完这个规模](../../src/amb/adapters/impl/a_mem/README.md#growth)，⚠️ 不在表内 |

⭐ **要把①和②变成结论，需要 n≥93 且跨多个对话**——
见[抽样](../sampling.md)里那张表。
