# agent-memory-bench

公平、公正、公开的 agent memory 能力评估框架。

> **⚠️ 当前状态：设计阶段，尚无实现。**
> 仓库里只有 [`docs/`](docs/)。适配器协议仍是草案，定稿之前不要开始写适配器。

## 它想解决什么

现有的 agent memory 评测，问题不在题不够多，在**三件事没分开**：

| | 现状 | 后果 |
|---|---|---|
| 「做不到」与「做错了」 | 记成同一个 0 分 | 没有某项能力的系统，和有能力但做砸的系统，读者分不出来 |
| 「我们的尺子」与「大家的尺子」 | 各家自己重写判分 | 同一系统同一数据集出现 **84% / 58.44% / 75.14%** 三个数 |
| 「记忆层的活」与「生成器的活」 | 只报端到端准确率 | 把别人的 backbone 算进自己的成绩 |

## 怎么做

**能用别人的尺子就用别人的。** 15 个公开题库覆盖到的能力——检索质量、冲突消解、
诚实弃权、记忆幻觉、成本延迟——一律调用它们、**用它们的判分代码**。
自己重写只会引入「我们的判分与别人不同」这个不可比性。

**自研题只补结构上测不到的八类**，它们来自两条独立的推导。

**防守性推导**——逐条比对公开题库，看它们漏了什么：

| | 考什么 | 为什么公开题库测不了 |
|---|---|---|
| **N1** 对现实求值 | 世界变了，你发现没有 | 公开题库全是静态语料，没有可被求值的"现在" |
| **N2** 原文回链 | 你说这条来自 X，X 真是来源吗 | 现有接口没有"出自原文哪一段"这一维 |
| **N3** 推理链 | 结论之外，每一步成立吗 | 只判最终答案，蒙对满分 |
| **N4** 治理 | 谁写的、谁能读、删了留痕吗 | 现有接口 `ask(question)` 不带"谁在问" |

**进攻性推导**——从认知科学反推记忆本该是什么样：

| | 考什么 | 为什么公开题库测不了 |
|---|---|---|
| **N5** 巩固与遗忘 | 该留的留了，**该丢的丢了吗** | 静态语料里不存在"间隔"，也不存在"未来" |
| **N6** 关联结构 | 可达性与扇形干扰 | 自然语料的图拓扑是碰巧长成的，不可控 |
| **N7** 置信度校准 | 它知不知道自己什么时候会错 | 弃权全是二元的，接口里没有置信度这个出口 |
| **N8** 归纳与可废止推理 | 归纳出规律，且**例外不推翻规律** | 没有题库提供带例外的、有统计规律的世界 |

⭐ 两条推导**独立地指向了 N1–N4 中的全部四个**——这是对这套设计最强的支持。

八类**全部确定性判分，不用 LLM 评委**——评委换一个分数就漂，
而这要当长期可比的尺子。

## 自己约束自己的三条

1. **只走公开接口。** ⛔ 这条对本项目作者自己的系统同样成立，而且首先针对它。
   一个能伸手进自己人内部的评测框架，公正性没法自证。
2. **机制中立。** 协议只说要回答什么，绝不说怎么做到。
   要求系统提供「断言」就是照着某一家写的。
3. **利益关系必须标注。** 题库由被测方维护、适配器由被测方提交、
   被测系统是本项目作者的——全部标出来，读者自己判断。
