# `corpora/` —— 真实语料（数据，不是代码）

**只干一件事**：存放**真实**的语料，用途只有两个。

| 用途 | 说明 |
|---|---|
| ⭐ **拟合需求概率曲线** | [world.md](../docs/adapters/world.md#need-probability) 要求经验曲线从真实语料测出，⛔ 不能自己编 |
| **合成语料的真实性对照** | 检验 `world/stream/` 造出来的事件流有没有失真 |

来源：真实的 agent 会话日志 · 工单流 · 提交历史 · [DSH 轨迹](../tools/README.md)。

## ⛔ 语料不是世界

语料是被 `ingest()` 进去的东西；世界是被**观察**的外部现实。
一段录下来的真实轨迹**没有配套的世界**——它没有需求概率真值、
没有种下的规律、没有已知失效的事实。

所以 corpora 里的东西**服务不了 N1 / N5 / N7 / N8**，
它们要的是 harness 拥有、ground truth 已知的世界。
⚠️ 拿真实语料跑那四类，得到的数没有真值可对，是个假的分。

## 可复现性

⛔ 用于拟合的语料，其**来源与拟合参数一并进[结果报告](../docs/report.md)**。
换一份语料就是换了一把尺子。
