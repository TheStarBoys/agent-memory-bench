# `world` —— 评测器 拥有的世界

**只干一件事**：把[声明式清单](../../../docs/adapters/world.md)物化成一个
可被系统只读、可被 评测器 改变、可复现的世界。

清单 · 物化（含 mtime 钉死）· 规范化序列化哈希 · 只读时钟端点 ·
只读事实表端点 · 五类变更 · [`stream/`](stream/) 事件流

⭐ **世界经由宿主的 `ctx.fs` seam 交付**，由 [`../agent/`](../agent/) 挂上去。
agent 能在世界里动手，但每次写都经过评测器——所以世界变化**可归因**。
⛔ 归属没有松动：世界仍归评测器所有。

⛔ **世界只对 评测器 可写。** 这一层不得暴露任何供被测系统写入的路径——
能写世界的系统可以靠改变现实让自己的记忆重新为真。
