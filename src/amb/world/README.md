# `world` —— harness 拥有的世界

**只干一件事**：把[声明式清单](../../../docs/adapters/world.md)物化成一个
可被系统只读、可被 harness 改变、可复现的世界。

清单 · 物化（含 mtime 钉死）· 规范化序列化哈希 · 只读时钟端点 ·
只读事实表端点 · 五类变更 · [`stream/`](stream/) 事件流

⛔ **世界里没有 agent。** 会写文件、跑工具的东西不可能是被观察的世界——
理由与真实语料该放哪，见 [ARCHITECTURE.md](../../../ARCHITECTURE.md)。

⛔ **世界只对 harness 可写。** 这一层不得暴露任何供被测系统写入的路径——
能写世界的系统可以靠改变现实让自己的记忆重新为真。
