# `world/stream` —— 事件流与统计结构

**只干一件事**：产生带统计结构的事件流与图结构，供 N3 / N5 / N6 / N7 / N8 使用。

频率 · 间隔 · 显著性（⛔ 三者必须正交可控）· 需求概率 ·
带例外的规律 · 可控的扇形度 · 从真实语料拟合经验曲线

⚠️ 这些生成器**决定语料量**，而语料量直接是钱和墙钟：
⭐ `mem0` 摄入 10.03s/条，`topology` 把扇形度开到 64 就多 226 条 ≈ +38 分钟。
⛔ 改任何一个生成器的默认值 = 语料指纹变了 = **全部摄入快照作废**，
旧存档不可与新跑并列。

⭐ **需求概率不能自己编**——自己拍一个分布等于自己定义什么叫「该记住」，
那就成了自证。做法见
[world.md · 需求概率不要自己编](../../../../docs/adapters/world.md#need-probability)。
