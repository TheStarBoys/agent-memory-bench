# `a_mem` —— 挑它是因为**对 LLM 的要求低**

⭐ A-mem 把**笔记之间的自组织链接**当主要问题：每条记忆存成一张 Zettelkasten
卡片（内容 + 上下文 + 关键词 + 标签），新卡片进来时跟邻居比对并演化链接。

⛔ **挑它的理由（提示只有 668 token，mem0 是 8413）被实测推翻了**：
按提示预算它该便宜一个数量级，实测反而更慢。原因写在
[llm-demand.md](../../../../../docs/llm-demand.md)：输出 token 才是大头，
而且它每进一条要跟已有邻居演化链接，**第 2 条起每条打 2 次 LLM，且随库变贵**。

⭐ 关掉 backbone 的思考模式之后，每条从 58–293 秒降到 **3–7 秒**
（3 篇端到端 663s → 43s）。⚠️ 「随库变贵」这个形状没变，
但它已经不是「贵到不能用」了。

⭐ 仍然真的那一条：embedding 用本地 `all-MiniLM-L6-v2`，**完全不走网络**。

| | |
|---|---|
| ⚠️ `ingest` 会调 LLM | 分析内容 + 可能触发演化——⭐ 成本那一栏必须一起读 |
| ⛔ 不声明 `PROVENANCE` | 它存的是**演化过的笔记**，不是原文片段，给不出区间 |
| ⛔ 不声明 `REALITY` | 它不对外部世界求值 |
| ⛔ 不声明 `GOVERNANCE` | 有 `delete()`，⚠️ 但没有主体隔离与审计日志——**只有删除接口不等于有治理能力** |

## ⛔ 三处我们改了它的默认行为

改上游默认值会让读数不再是「它出厂的样子」，所以每一条都得有理由、都得写出来。

| 改了什么 | 为什么非改不可 |
|---|---|
| 用 `OPENAI_BASE_URL` 环境变量指端点 | 它写死 `OpenAI(api_key=...)`，⛔ 没有 `base_url` 参数。用环境变量搭桥是为了**不改它的源码**（[原则④](../../../../../docs/adapters/README.md#p4)） |
| `temperature` 钉成 `0.0` | 它调 `get_completion` 时不传温度，⛔ 默认 **1.0**。①判分不可复现 ②[LLM 缓存](../../llm_cache.py)只缓存 0.0，否则**静默失效**——mem0 上踩过，表现是命中数恒为 0 且不报错 |
| `storage_path` 每条臂独立 | ⛔ 共用一个 chroma 目录会让两条臂互相污染 |

## ⚠️ 首跑实测（2026-09-02，3 篇中文文档）

### ⚠️ 演化可能造出**对不回原文**的记忆

**backbone 思考开着**那一跑：3 篇文档摄入后 `count()` 返回 **4**，
多出来的那条内容与 D1 重复但**没有 doc_id**——它是演化过程新建的，
⛔ 不在 `add_note()` 的返回里，适配器的记账拿不到它。

⭐ 关掉思考重跑：`count()` 回到 **3**，每条结果都带 doc_id。

⛔ **别从 n=3 得出「关了思考就不会发生」**——只能说这一跑没发生。
⚠️ 但后果是确定的：检索命中一条没有 doc_id 的记忆，按我们的口径
**算不上命中**。这不是适配器的 bug，是这个系统的真实形状——
⛔ 所以它不声明 `PROVENANCE`。

### ⛔ 本地 embedder 在中文上很弱

问「公司在哪」，正确答案 D3（「凌霄科技的总部在杭州西湖区」）
排在**最后**，最前的是与问题无关的 D2。⚠️ 换 backbone、关思考都不影响这一条——
⭐ 这正说明问题出在 embedder，不在 LLM。

⚠️ `all-MiniLM-L6-v2` 是英文语料训出来的。⛔ 所以 a_mem 在中文题库上的
检索分**混进了 embedder 的语言短板**，不能全算到记忆机制头上。

## ⚠️ 跟其他臂比较时要记着的一条

它的 embedding 是**本地** `all-MiniLM-L6-v2`，其他臂用的是配置里那个
`AMB_EMBED_MODEL`。⛔ 所以 a_mem 与 naive_rag / hybrid 的检索分差里
**混进了 embedder 的差别**，不能全算到记忆机制头上。

## ⛔ 0.2.6 与 GitHub main 的两处差别

照着仓库 main 分支写适配器会静默出错，实测：

- `search()` 返回里**没有 `content`**，只有 `id` / `context` / `keywords` / `tags` / `score`——
  ⚠️ 取原文要按 id 再 `read()` 一次。
- `self.memories` 字典**已被拿掉**（换成 LRU 缓存），chroma 才是唯一真相源——
  ⛔ 照抄旧版的 `len(self.memories)` 会恒返回 0。

`score` 是 chroma 的**距离**不是相似度。⛔ 不做换算，判分只用排序。

版本由 [`setup`](../../../setup/README.md) 钉死并记录实际装到的那个。
