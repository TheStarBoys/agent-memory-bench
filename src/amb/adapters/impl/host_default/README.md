# `host_default` —— 裸宿主

⭐ **真实地板。** 不挂记忆插件，只用 agent 宿主自带的上下文管理与压缩。

不挂记忆插件 **≠ 没有记忆**：DSH 自带最近轮次的工作记忆、`ctx.compaction`、
文件引用——那本身就是一套记忆策略。所以真正要回答的问题是：

> **你比「让宿主自己压缩上下文」强吗？**

⚠️ 一个跑不赢这条线的记忆系统，等于在给 agent 添麻烦。
这条线会很难看，但它是最该报的一条。

⭐ 预期它在 [N1](../../../../../docs/suites/n1-reality.md) 上接近满分——
每次重读文件的 agent 永远看到当前世界，「记忆过时」对它不存在。
那不是 N1 出错，见 [baselines.md](../../../../../docs/baselines.md)。
