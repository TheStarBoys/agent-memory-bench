# `hybrid` —— BM25 + embedding，倒数排名融合

⭐ **为什么加它**：[LoCoMo 首跑](../../../../../docs/runs/2026-09-02-locomo-first.md)
显示两种检索**各有主场**——

| | bm25 | naive_rag |
|---|---:|---:|
| 弃权题 | **0.714** | 0.500 |
| 单跳事实 | 0.516 | **0.710** |

所以混合**应当两边都拿到**。⚠️ 这是一个可检验的预测：
⛔ 如果混合没赢，说明「各有主场」那个观察是噪声。

## ⚠️ 用 RRF 不用分数加权

⛔ BM25 分与余弦相似度**量纲不同**，直接加权等于随手定了个汇率——
那个汇率会变成一个没人验证过的超参。
RRF 只用**排名**，⭐ 不需要那个汇率。

⚠️ `RRF_K=60` 是原论文取值，⛔ **我们不调它**——
调参会让「混合更好」变成「我们把混合调好了」。
