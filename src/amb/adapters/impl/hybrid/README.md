# `hybrid` —— BM25 + embedding，倒数排名融合

⭐ **为什么加它**：[LoCoMo 首跑](../../../../../docs/runs/2026-09-02-locomo-first.md)
显示两种检索**各有主场**——

| | bm25 | naive_rag |
|---|---:|---:|
| 弃权题 | **0.714** | 0.500 |
| 单跳事实 | 0.516 | **0.710** |

所以混合**应当两边都拿到**。⚠️ 这是一个可检验的预测：
⛔ 如果混合没赢，说明「各有主场」那个观察是噪声。

## ⚠️ 用 RRF 不用分数加权

⛔ BM25 分与余弦相似度**量纲不同**，直接加权等于随手定了个汇率——
那个汇率会变成一个没人验证过的超参。
RRF 只用**排名**，⭐ 不需要那个汇率。

⚠️ `RRF_K=60` 是原论文取值，⛔ **我们不调它**——
调参会让「混合更好」变成「我们把混合调好了」。

## ⭐ 预测的验证结果：**部分成立**，反例更有价值

LoCoMo 分层 120 题实测：

| 类 | `bm25` | `naive_rag` | **`hybrid`** | |
|---|---:|---:|---:|---|
| 时间推理 | **0.840** | 0.680 | **0.840** | ✅ 追平最好 |
| 弃权 | 0.690 | 0.655 | ⭐ **0.793** | 超过两者 |
| 开放域推断 | 0.333 | 0.333 | ⭐ **0.556** | 超过两者 |
| 单跳事实 | 0.520 | **0.680** | 0.660 | ≈ 追平 |
| **多跳** | 0.152 | **0.424** | ⛔ **0.212** | **掉了** |
| 总分 | 0.514 | 0.596 | 0.610 | |

⛔ **多跳那一格是反例**：混合 0.212 远低于纯向量的 0.424。

⚠️ 原因说得通：多跳要跨轮次拼线索，靠的是**语义邻近**；
RRF 让 BM25 的词面匹配挤进 top-k，把语义邻居**挤出去了**。

⭐ **这比「混合全赢」有价值**——它说明融合不是免费的，
而 `RRF_K=60` 这个不调的常数在多跳那一类上是错的选择。
⛔ 我们不因此调它：调了就变成「我们把混合调好了」，
⚠️ 而那个数字不再能回答「混合本身好不好」。

⚠️ 报告仍判「⛔ 分不开（差 +0.014，n=120 只能辨 ≥0.168）」——
**判分纪律没被结果带偏**。要证实总分优势，按
[要多少题](../../../../../docs/sampling.md#how-many) 得再加题。
